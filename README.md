## 🛠️ Projects Overview

### 01. Spring Boot Web (`01-springbootweb`)
- **Description**: Foundation of Spring Boot RESTful web services.
- **Key Concepts Covered**:
  - REST Controllers (`@RestController`, `@RequestMapping`, `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`, `@PatchMapping`)
  - Request & Response Handling (`@RequestBody`, `@PathVariable`, `@RequestParam`, `ResponseEntity`)
  - DTO Pattern & ModelMapper integration
  - Input Validation with Jakarta Validation (`@Valid`, custom validation annotations)
  - Global Exception Handling (`@RestControllerAdvice`, `@ExceptionHandler`)
  - Unified API Response Wrapper (`ApiResponse<T>`, `ResponseBodyAdvice`)
  - H2 Database integration with Spring Data JPA
